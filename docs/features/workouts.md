# Тренировки: итерация 2 (1 октября 2026)

Статус: журнал подходов, продолжение после закрытия и история реализованы. Проверено в симуляторе iPhone 18 Pro (iOS 27.0): сборка, автотесты (259 в 21 наборе, все прошли), ручной проход тренировки с закрытием приложения посреди отдыха. Не проверено: iOS 18.6, физический iPhone, реальная доставка уведомления об отдыхе.

План сейчас — **стартовый**: он составлен по общим правилам из ответов анкеты, а не по материалам тренера. Интерфейс говорит об этом прямо («Стартовый план по общим правилам» с пояснением по нажатию). Настоящий алгоритм остаётся последней функциональной итерацией.

## Сегодня

Экран «Сегодня» (`Features/Today`) определяется `TodayResolver` по слотам расписания, см. [расписание](schedule.md). Состояния:

- **Тренировка.** Название дня и группы мышц, упражнения с подходами и повторами, примерная длительность, кнопка «Начать тренировку». Если упражнения заменены из-за отмеченных зон — строка «Обошли нагрузку на: …». Если для слота есть незавершённая тренировка, вверху плашка «Продолжить».
- **Сделано.** Итог сохранённой тренировки.
- **Пропущена / на паузе.** Короткое пояснение и ближайшая следующая тренировка.
- **День отдыха.** «Восстановление»: следующая тренировка, дата переноса, если она сдвинута, и два необязательных занятия. Они не засчитываются как тренировка по плану и не влияют на серию.
  - «Кардио» — разминка, основной блок, растяжка. Основной блок: ходьба в горку, велотренажёр, эллипс или гребля, по номеру дня и без нагрузки на отмеченные зоны. 15–30 минут по уровню.
  - «Лёгкий блок» — барабан останавливается на случайном блоке: пресс, руки, мобильность или ягодицы с кором.

## План

Генератор — `Domain/WorkoutPlanner.swift`. Правила простые, это не медицинская оценка.

- **Сплит по числу дней:**

  | Дней | Сплит |
  |---|---|
  | 1 | всё тело |
  | 2 | верх / низ |
  | 3 | тяни / толкай / ноги |
  | 4 | верх / низ × 2 |
  | 5 | тяни / толкай / ноги + верх / низ |
  | 6–7 | тяни / толкай / ноги × 2 + всё тело |

  День недели берёт шаблон по своему месту среди выбранных дней. По чётности номера недели кандидаты чередуются.
- **Нагрузка по цели:**

  | Цель | Подходы × повторы | Отдых |
  |---|---|---|
  | Набор | 4 × 8–12 | 90 с |
  | Сушка | 3 × 12–15 | 45 с |
  | Поддержание | 3 × 10–12 | 60 с |

  «С нуля» и «после перерыва» получают на 1 подход меньше, «опытный атлет» — на 1 больше. Упражнений 4–6, по уровню.
- **Ограничения.** У каждого упражнения каталога есть список нагружаемых зон `BodyZone`. Упражнение, которое нагружает отмеченную зону, заменяется следующим кандидатом слота.
- **Добор.** Если зон отмечено много и шаблон не набрал дневную норму, планировщик проходит по всем слотам шаблона, а затем добирает безопасные упражнения: сначала группы дня, потом кор, ягодицы, мобильность, ноги. Ни одно из них не нагружает отмеченные зоны. Группы, попавшие в день из добора, добавляются в его «акцент». До этого исправления план при многих ограничениях мог сводиться к одному упражнению.
- **Калибровка.** Берётся последняя оценка упражнения:
  - «легко» — +2 повтора (у упражнений на время +10 с);
  - «на пределе» — −1 подход и −2 повтора (−10 с);
  - «в самый раз» и «тяжело» — без изменений.

  Причина видна в списке упражнений.

## Сессия

Состояние ведёт `Features/Workout/WorkoutSession.swift`, экраны — `WorkoutSessionView`, `ExerciseRunnerView`, `WorkoutRatingView`, `WorkoutSummaryView`.

- **Список.** У каждого упражнения полоска подходов и отметка о выполнении, сверху общий секундомер, счётчики «Упражнений: 1 из 5» и «Подходов: 3 из 15» и заметная полоса прогресса. Внизу одна главная кнопка: «Начать тренировку», затем «Продолжить»; «Завершить досрочно» — второстепенное действие под ней.
- **Подход.** Тап по упражнению начинает подход. Над вводом стоит фигура с подсвеченными мышцами упражнения (`ExerciseFigure`). Карточка ввода показывает прошлый раз («Прошлый раз: 60 кг × 10, 60 кг × 9»; для упражнений без веса коротко: «17, 18, 18 повторений»), вес и повторы уже заполнены. Подход «как в плане» — одно нажатие. Значения меняются кнопками − / + или вводятся с клавиатуры: при входе в поле старое значение уходит в подсказку, число принимается сразу, кнопка «Готово» убирает клавиатуру. У упражнений на время вместо повторов кольцо до цели.
- **Вес по умолчанию.** Если вес упражнения ещё неизвестен, под вводом появляются быстрые значения (10–50 кг) и выбор шага кнопок − / + (1 / 2,5 / 5 кг).
- **Тип подхода.** Переключатель «Рабочий / Разминка / До отказа / Дроп-сет» (`SetKind`). Разминка не входит в плановые подходы, объём и рекорды и идёт без отдыха; в списке записанных подходов она подписана «Разминка», а рабочие нумеруются 1, 2, 3… (`[SetEntry].rowTitles`). Сводки и счётчики (в том числе «Незавершённая тренировка» на «Сегодня») считают только рабочие подходы. Старые записи без типа читаются как рабочие.
- **Что подставляется.** Последний рабочий подход этой тренировки, иначе тот же подход прошлого раза (разминки прошлого раза не в счёт), иначе числа плана. Вес показывается только у упражнений, которым он нужен (`ExerciseInfo.usesWeight`).
- **Отдых.** После подхода обратный отсчёт; кнопки «15 с», «Пропустить», «Начать подход N». Колокольчик уведомления об отдыхе стоит в шапке экрана упражнения. Если он включён, на момент конца отдыха ставится локальное уведомление; оно видно, только когда приложение не на экране, и снимается вместе с отдыхом.
- **Кардио.** Вместо «подходов» — «блоки» («Блоков: 0 из 3», «Блок сделан», «Цель 5 мин»); словарь задаёт `SetWords`. Кольцо таймера отцентровано.
- **Правка.** Сделанный подход можно изменить или удалить; упражнение, у которого подходов стало меньше нормы, снова становится рабочим.
- **Техника.** Кнопка у упражнения открывает карточку: фигура спереди и сзади с подсвеченными мышцами, их названия и три совета. Данные — `Domain/ExerciseInfo.swift`, все 49 упражнений каталога; названия мышц сверяет с ассетами тест.
- **Оценка.** Четыре варианта в одном стеклянном переключателе (`GlassSegmented`, режим `tight`): «Легко», «В самый раз», «Тяжело», «На пределе». По умолчанию стоит «В самый раз», чтобы не заставлять отвечать на каждое упражнение. С экрана оценки можно вернуться к тренировке («К тренировке»).
- **Итог.** Минуты, подходы, объём в кг. Рекорды (`Domain/Records.swift`, `PersonalRecords`) — не больше одного на упражнение, по приоритету: вес → расчётный максимум на 1 повторение (формула Эпли) → повторы → объём; первый раз упражнение рекордом не считается, разминки в рекорды не входят. Объём сравнивается с прошлым разом по тем упражнениям, которые делались и тогда. Частичная тренировка получает заголовок «Тренировка записана» и «Частично: 3 из 15 подходов», без кубка.
- **Выход.** Можно завершить в любой момент: частичная тренировка сохраняется как неполная (`setsDone` меньше `setsPlanned`) и засчитывается. Выйти без сохранения тоже можно.
- **Таймеры хранят даты, а не счётчики**, поэтому после сна приложения время верное.

## Продолжение после закрытия

Каждое изменение сессии записывает её снимок (`SessionSnapshot`) в хранилище под ключом `activeSession`. При запуске приложение находит снимок и показывает «Продолжить». Фаза, подходы, оценки и конец отдыха восстанавливаются; таймер отдыха продолжает идти по сохранённой дате. Снимок, который уже не подходит к плану (например, план изменился), отбрасывается, а не показывается неверно. Повторное нажатие «Начать» для слота, у которого есть снимок, продолжает его, а не начинает новую тренировку.

Сохранение тренировки использует идентификатор сессии как идентификатор записи, поэтому повторное сохранение того же занятия даёт одну запись.

## Хранение

Журнал `[WorkoutLog]` лежит в хранилище «ключ → JSON» под ключом `workoutLogs`; запись содержит подходы (`SetEntry`: вес, повторы или секунды и тип `kind`), `sessionKey` слота и `plannedSets`. Старые записи без этих полей читаются. Если основной журнал не читается, он не удаляется и не перезаписывается: новые тренировки идут под ключ `workoutLogs.recovered` и сливаются обратно, когда основной журнал снова читается. Ошибка записи показывается на экране оценки, сохранение можно повторить. См. [модель данных](../architecture/data-model.md).

## Пока нет

- Live Activity и Dynamic Island для таймера отдыха (отдых — локальное уведомление): для них нужна отдельная цель виджета в проекте, это отдельная задача.
- Видео техники упражнений: нет материала, пока только статичная карточка.
- Замены упражнения во время тренировки, RIR, карты восстановления.
- Анимаций техники упражнений (есть статичная карточка с подсветкой мышц).
- Реального алгоритма по материалам тренера.

## Итерация 8 аудита: мелочи экрана тренировки (1 октября 2026)

- **Карточка техники.** Сверху кнопка «Закрыть» (раньше лист закрывался только жестом). Показываются только стороны тела с подсвеченными мышцами: у «Птицы-собаки» одна задняя фигура на всю карточку вместо тусклого силуэта рядом; фигуры ниже, так что три совета «Как делать» видны без прокрутки. Мобильность, как и кардио, получила значок движения вместо обрезанной мышцы.
- **Выход без сохранения.** Если в тренировке уже есть записанные подходы, после «Выйти без сохранения» спрашивается ещё раз («Удалить без сохранения?», «Вернуться к тренировке»). Пустую тренировку закрывает сразу.
- **Верх экрана упражнения.** «К списку» и «Техника» увеличены до размера основного текста и 48 pt высотой. Колокольчик сигнала об отдыхе отвечает словами: «Сигнал включён: скажем, когда отдых закончится, даже если экран погас» или «Сигнал выключен».
- **Оценка.** Пояснение сокращено до одной строки: «Отметь, как прошло каждое упражнение: по этому уточним следующую нагрузку».
- **Итог.** Заголовок выполненной тренировки — «Тренировка выполнена» (вместо «в копилке»); неполной — «Тренировка записана».
- **Словарь.** Единые названия понятий записаны в [дизайн-системе](../design/design-system.md#словарь-интерфейса-итерация-8-аудита-1-октября-2026).
