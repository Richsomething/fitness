# FelixGlass

Стекло для SwiftUI-приложений: поверхность, кнопки, сегментированный переключатель с линзой, панель вкладок и фон листа. Написано для Maestro Felix, но ничего о нём не знает: цвета приложение передаёт само.

**Два вида стекла.** На iOS 26 и новее (в том числе iOS 27) рисует системное Liquid Glass (`glassEffect`, `GlassEffectContainer`). На iOS 18–25 рисует своё матовое стекло: размытие, светлое тело, свет сверху, яркая кромка и мягкая тень. Выбор делает `GlassEngine`: по умолчанию `.automatic`, `.frosted` всегда включает матовое.

Минимальная версия iOS 18. Матовые значения подобраны под тёмный фон. Ветка системного стекла собирается только в Xcode 26 и новее (`#if compiler(>=6.2)`), с более старым Xcode пакет соберётся без неё.

## Подключение

Локальный пакет: в Xcode «File → Add Package Dependencies → Add Local…» и папка `Packages/FelixGlass`, либо запись `XCLocalSwiftPackageReference` в проекте (как в `MaestroFelix.xcodeproj`).

```swift
import FelixGlass

// Один раз у корня приложения: свои цвета.
ContentView()
    .environment(\.glassPalette, GlassPalette(accent: .blue, accentDeep: .indigo))
```

## Что внутри

| Что | Для чего |
| --- | --- |
| `glassSurface(in:style:interactive:)` | стекло за любым видом, обрезанное формой |
| `GlassStyle` | пресеты `.regular`, `.clear`, `.accent`, `.lens` и `.tinted(_:)` |
| `GlassButton` | кнопка во всю ширину, `.primary` (цветное стекло) и `.secondary` |
| `GlassIconButton` | круглая кнопка с символом и подписью для VoiceOver |
| `GlassSegmentedControl` | выбор из нескольких вариантов, `GlassDensity` задаёт размер |
| `GlassTabBar`, `GlassTabItem` | панель вкладок одной капсулой, рисует и сообщает выбор |
| `GlassSelectionLens` | линза под выбранным; одинаковый `matchedGeometryEffect` двигает её |
| `GlassGroup` | на iOS 26+ объединяет соседние стёкла в один материал |
| `glassSheet(detents:)` | оформление листа: системное стекло на iOS 26+, тёмный фон раньше |
| `GlassPalette`, `GlassEngine` | цвета и выбор вида стекла через environment |

## Правила

- Стекло для того, что плавает над содержимым: панели, переключатели, кнопки, капсулы. Карточки со списками и текстом не делаем стеклом.
- Стеклу нужно что-то позади: однотонный чёрный фон его не показывает. Под панелью вкладок кладут мягкое цветное свечение.
- Подпись у каждой кнопки-иконки обязательна (`GlassIconButton` требует её в инициализаторе).

## Проверка

Тесты проверяют значения, из которых стекло рисуется (прозрачности, плотность, тинт): `GlassStyleTests`. Как стекло выглядит, проверяется только на экране: на iOS 27 и на iOS 18.6, где работает матовая ветка.
